# Portuguese for Mozambican Mothers: Project Showcase

A static showcase page for **Portuguese for Mozambican Mothers – A Language Empowerment App**, built during my Santa Clara University senior design project (2024–25) and the follow-on CSEN 493 work (2025–26).

**Live:** https://joshsj89.github.io/mozambique-showcase

## Related

- Senior thesis: [Scholar Commons #330](https://scholarcommons.scu.edu/cseng_senior/330)

## Structure

```
index.html        single-page showcase
styles.css        styles (light/dark via prefers-color-scheme)
assets/
  favicon.svg
  img/            screenshots, slide crops and diagrams
  docs/poster.pdf senior design poster
```

No build step. Open `index.html` locally, or push to `main` and GitHub Pages serves it.
